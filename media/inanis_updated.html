Save vs overwrite
One creates a file, the other rewrites it.
save_document()
Creates a new file. If the desired path already exists, it finds another available path.
NewDoc4.txtalready exists
↓
NewDoc4(1).txtalready exists
↓
NewDoc4(2).txtcreated
The number in (n) keeps rising until a path is free.
overwrite()
Writes back to the existing document. No new file is created.
NewDoc4.txtupdated in place
New documents use save_document(); existing ones use overwrite().
